3. 이해해야 할 문제와 데이터

공식 대상은 FeMoCo76o113e: 공간 오비탈 76개, 전자 113개다. 주어진 해밀토니안을 근사한 수치 데이터와, 그 데이터를 각도로 로딩하는 회로가 함께 평가된다. 공식 FCIDUMP·전자 수·기준 에너지·고정 shift를 평가 기준으로 사용한다.

항목기준 구조서희가 설명할 내용
R / B / C65 / 60 / 60제공된 분해의 크기 파라미터. 바꾸면 재구성 오차와 자원 비용을 함께 확인
U(65, 60, 76)제출 벡터의 형상. 실제 평가는 회로에서 읽은 각도로 복원한 벡터를 사용
W / H2_I분해 가중치·수치 파라미터각도에서 복원한 벡터와 함께 해밀토니안 근사에 들어가는 값
H1_I / Hsym_lowerNPZ에 포함공식 평가는 제공된 고정 shift를 사용하며, 제출된 이 값들을 그대로 채점에 사용하지 않음
tree_edges(75, 2)각도 단어에서 76차원 벡터를 복원하는 트리 순서
angle_words(3976, 75)76개 one-body 행과 R×B개 two-body 행의 정수 각도 표. 샘플 NPZ의 회로 생성 보조 자료
brot / J12 / 8각도 단어 비트 수 / 회로 한 개가 처리하는 단어 수
ANGLE 회로10개ceil(75 / J)개. 대응 NPZ와 같은 설정에서 생성되어야 함

각도 해석식은 theta = pi × word / 2^(brot−1)이다. 정밀도를 낮출 때는 실제 각도를 그 정밀도에 맞춰 다시 양자화한다. 기존 12비트 정수를 그대로 11비트로 해석하면 각도 자체가 달라진다.

4. 기준 결과와 공식 통과 조건

아래 값은 2026-11-07 공식 화학 예제의 로컬 full PASS 기록이다. 표시값은 반올림했으며 정확한 비교에는 원본 JSON을 사용한다. 이 문서를 만들면서 새 후보를 실행하거나 대회에 제출한 것은 아니다.

지표기준값의미와 판정 기준
error_10.00318519503 Ha1전자 성분 재구성 잔차. ≤ 0.020 Ha.
error_20.01863957063 Ha2전자 적분 재구성 잔차. ≤ 0.020 Ha.
Lambda308.45593973309 HaLCU 정규화 계수. > 49.0을 엄격하게 만족.
E_SOS-22144.23882724429 HaDFTHC 해밀토니안의 SOS 에너지 하한.
E_gap3.96547724429 HaE_upper − E_SOS. > 3.914898 Ha와 공식 gap_in_domain 검사 충족.
lambda_eff49.30136925057 Hasqrt(E_gap × (2 Lambda − E_gap)). 유한값이어야 함.
전체 Toffoli / 전체 큐비트93,237 / 730전체 블록 인코딩 자원. 개별 ANGLE 자원과 구분.
공식 로컬 비용 score3,355,599,588.3155375lambda_eff × 전체 Toffoli × 전체 큐비트. 같은 과제에서 낮을수록 유리.

error_1과 error_2는 재구성 잔차의 Frobenius norm이다. 실제 바닥상태 에너지 오차와 같은 값으로 해석하지 않는다. E_gap은 고정 E_upper와 SOS 하한의 차이이며 들뜬 상태와 바닥상태의 에너지 차이를 직접 계산한 값이 아니다.

현재 error_2의 남은 여유는 약 0.00136043 Ha, 즉 1.36043 mHa다. 허용치의 약 93.2%를 이미 사용하므로 정밀도를 낮추는 실험에서 특히 확인할 지표다. 이 여유만으로 후보의 전체 통과를 예측할 수는 없다.

기준 회로 검증은 주소당 64 shots, 총 254,464 shots를 사용했다. ANGLE 회로의 큐비트 수는 119, 전체 비용식의 큐비트 수는 730이다. 각 ANGLE 회로의 한도는 128큐비트다. 수치 모델 통과, 축소 smoke 통과, 전체 full 통과를 나눠 기록한다.

5. 오늘 바로 해볼 결과 읽기

PowerShell에서 아래 명령은 저장된 JSON만 읽는다. 화학 시뮬레이션이나 패키지 설치를 실행하지 않는다. 드라이브 문자가 다르면 $ProjectRoot에 본인 PC의 jjeya 폴더 경로를 지정한다.

Set-Location -LiteralPath (Join-Path $ProjectRoot 'seohee_work\week1')
$SeoheeBaselinePath = '..\..\seojin_work\week1\reports\runs\20261107T091146680709Z-full\dfthcsos.json'
$SeoheeReport = Get-Content -LiteralPath $SeoheeBaselinePath -Raw -Encoding UTF8 | ConvertFrom-Json
$SeoheeMetrics = $SeoheeReport.official_result.metrics

$SeoheeMetrics | Format-List
[pscustomobject]@{
    Status = $SeoheeReport.official_result.status
    Score = $SeoheeReport.official_result.score
    VerifiedShots = $SeoheeReport.official_result.verified_shots
    Error1Margin_mHa = (0.020 - $SeoheeMetrics.error_1) * 1000
    Error2Margin_mHa = (0.020 - $SeoheeMetrics.error_2) * 1000
    SubmissionSHA256 = $SeoheeReport.official_result.submission_sha256
} | Format-List

출력에서 PASS, 254,464 shots, error_2 여유 약 1.36043 mHa를 확인하고 baseline_review.md에 기록한다. submission_sha256은 공식 검증기가 정의한 전체 제출 묶음의 해시이며 JSON 파일 자체의 해시와 구분한다.

NPZ 배열을 직접 확인하거나 수치 모델을 다시 평가할 때는 지우 가이드의 2~4절을 순서대로 따른다. 그 실행 명령의 작업 위치는 seojin_work/week1이며, 이 가이드의 메모 작성 위치인 seohee_work/week1과 다르다.

8. 지우와 논의할 첫 가설 두 개

가설 예시서희가 확인할 내용지우·서진에게 요청할 결과
각도 정밀도 12→11비트올바르게 재양자화했는지, 특히 error_2 여유와 Lambda·E_gap 조건이 유지되는지새 단어 표의 수치 지표, 대응 NPZ·ANGLE 회로, full 상태·전체 비용
같은 12비트 각도에서 J=8→4물리적 각도와 복원 벡터가 유지되는지, 수치 지표가 같을 것으로 예상되는 근거회로 수·ANGLE 큐비트·전체 Toffoli·전체 큐비트·score 변화

위 두 항목은 실험 제안이며 통과나 비용 개선이 확인된 후보가 아니다. 후보 채택은 공식 정확도 조건을 만족한 상태에서 전체 비용이 낮아지는지로 판단한다. J는 회로당 단어 묶음 크기이므로, 각도 정밀도 brot와 구분한다.

  • 서진: 실험에서 참조한 NPZ·ANGLE·트리의 경로와 설정, 제출 해시, 실행 환경이나 회로 대응에서 확인이 필요한 질문을 전달한다.

후보를 검토할 때는 실험 ID → 입력·생성 설정 → 수치 모델 결과 → full JSON·로그 → 판단이 연결되게 남긴다. 원본 공식 파일을 수정하지 않고 실험별 복사본과 기록으로 비교한다.

근거 자료는 공통 폴더의 공식 설명·검증 코드와 2026-11-07 full 결과다. 관련 안내: 소연 가이드, 예찬 가이드, 공식 파일 무결성 기록. 역할과 첫 주 일정은 팀 실행 제안이다.
